
### Install homebrew

**/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"**

### install sdkman

**brew install sdkman**

or follow instructions at:

**https://sdkman.io/install/**

### install gradle

**sdk install gradle x.y.z (x,y,z = whatever latest version)**

### install java26 with fx

**sdk install java 26.fx-zulu**

### install git

**brew install git**

or follow instructions at:

https://git-scm.com/downloads

### get the source code

**git clone https://github.com/philgentric/klikr.git**

this will create a folder "klikr"

### start klikr!

**cd klikr**

**gradle run**

or:

**gradle klikr**
